# TraxAI Desktop

Official public releases of the TraxAI Desktop app.

## Download (Windows)

Download the latest version here:

https://github.com/teamdeveloperpro-sys/traxai-desktop/releases/latest

1. Download `TraxAI-windows-x64.exe`
2. Run it and follow the installer steps
3. Launch TraxAI

No account needed to download or install.
